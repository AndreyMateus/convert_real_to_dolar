# 💱 Conversor de Real (BRL) para Dólar (USD)

Este projeto é um site simples para realizar a conversão de valores de **Real Brasileiro (BRL)** para **Dólar Americano (USD)** utilizando a **API de cotação do dólar do Banco Central do Brasil (PTAX)**.

O objetivo do projeto é demonstrar o consumo de uma API pública, tratamento de dados e exibição de resultados de forma clara, com uma interface moderna e suporte a **tema claro e dark mode**.

---

## 🧠 Funcionalidades

- Conversão de valores de BRL para USD
- Consumo da API de Dados Abertos do Banco Central do Brasil
- Exibição da data da última atualização da cotação
- Interface moderna utilizando Tailwind CSS
- Tema claro e modo escuro (Dark Mode)
- Layout responsivo e amigável

---

## 🛠️ Tecnologias Utilizadas

- **PHP**
- **HTML5**
- **Tailwind CSS**
- **JavaScript (básico, para alternar tema)**
- **API PTAX – Banco Central do Brasil**

---

## 🔌 API Utilizada

A cotação do dólar é obtida através da API oficial de dados abertos do Banco Central do Brasil:

- Fonte: PTAX – Banco Central do Brasil  
- Documentação: <https://olinda.bcb.gov.br/olinda/servico/PTAX/versao/v1/aplicacao>

## 🚀 Como Executar o Projeto

### Opção 1 — Executar localmente (recomendado para estudos)

Para rodar o projeto localmente, você precisa de um ambiente que execute PHP.

Você pode usar qualquer uma das opções abaixo:

- **XAMPP**
- **Laravel Herd**
- **Laragon**
- **WAMP**
- Ou qualquer stack PHP similar

#### Passos

1. Instale um dos ambientes citados acima
2. Coloque o projeto dentro da pasta de servidor  
   - Exemplo no XAMPP:  

     ```
     C:\xampp\htdocs\conversor-brl-usd
     ```

3. Inicie o servidor (Apache)
4. Abra o navegador e acesse o seu localhost ou endereço definido pelo AMBIENTE (software que simula o servidor, Ex: xampp, Laravel herd, etc...)
